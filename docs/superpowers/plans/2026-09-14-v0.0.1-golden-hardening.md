> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make secondbrain 0.0.1 install, update, uninstall, and log every completed agent turn reliably across Windows Native, WSL, hybrid, Linux, and macOS.

**Architecture:** Centralize executable discovery and platform/path contracts, normalize all provider events into one durable turn-log pipeline, and protect filesystem mutations with staging, atomic writes, idempotency, and recovery. Verify behavior through temporary HOME/vault integration tests plus honest host-specific smoke reports.

**Tech Stack:** Python 3 standard library, PowerShell 5.1/7, POSIX shell, unittest, JSON/TOML config, git.

**Spec:** `docs/superpowers/specs/2026-09-14-v0.0.1-golden-hardening-design.md`

## Global Constraints

- Product source of truth is the `secondbrain` repository; `testOS` is only a live validation vault.
- Supported targets are Windows Native, WSL, hybrid Windows+WSL, Linux, and macOS.
- Provider coverage includes Codex/ChatGPT, Claude Code, Cursor, Antigravity, Gemini, and future adapters through the normalized event contract.
- No new third-party runtime dependency may be required for core install or logging.
- User-authored files and unrelated global agent configuration must survive install, update, and uninstall.
- A platform not exercised on a real host must be reported `NOT VERIFIED`, never passed by inference.
